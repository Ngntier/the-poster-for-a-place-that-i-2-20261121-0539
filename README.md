EMBERFALL — a travel poster for a place that does not exist: a volcanic island at dusk where rivers of molten light run down a black volcano into a glowing bay, under a low gold sun. Drawn entirely in code by a pure-stdlib Python program (main.py), deterministic, 1024×1024 PNG.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (or `$POSTER_OUT` when set for local testing).
